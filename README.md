# Abyssal Orbit — 메인트 카드 메이커 v8

## v8 변경사항
- 메인 글씨색 직접 선택 기능 추가
- 밝은 배경에서도 읽히도록 카드 내부 색상 체계 개선
  - 본문 글씨 → 메인 글씨색
  - 보조 글씨 → 메인 글씨색에서 자동 파생
  - 박스/구분선 → 메인 글씨색에서 자동 파생
  - 포인트 글씨는 기존 별빛/심해빛 색 유지
- 밝은 배경 프리셋 전면 재조정
  - Abyss: 기존 다크 우주/심해
  - Aurora: 밝은 민트-보랏빛
  - Monochrome: 밝은 회백색
  - Spring: 연분홍 바탕 + 녹색 포인트
  - Summer: 밝은 아쿠아/하늘색
  - Autumn: 크림/브라운
  - Winter: 아주 옅은 아이스 블루
- 각 프리셋은 별빛 / 심해빛 / 배경색 / 메인 글씨색 / 별 색상을 한 번에 적용
- 적용 후 개별 색상 수정 가능
- 기존 폰트 / 글자 크기 / 태그 카테고리 / 페어 3종 / PNG / JSON 기능 유지
