# Abyssal Orbit — 메인트 카드 메이커 v4

## v4 변경사항
- 별 밀도 대폭 완화
- 점 형태 별의 간격을 넓히고, 큰 ✦ / ✧ 장식 별 개수를 크게 줄임
- 글자 크기 선택 기능 추가
  - 작게 90%
  - 기본 100%
  - 크게 112%
  - 아주 크게 125%
- 선택한 글자 크기는 카드 전체와 PNG 저장 결과에 적용
- Nanum Pen Script는 기본적으로 조금 크게 보정하되, 글자 크기 옵션과 함께 조절 가능
- v3의 독립 스크롤 / 2열 페어 / 폰트 선택 / PNG / JSON 기능 유지
