# Abyssal Orbit — 메인트 카드 메이커 v22

## v22 이미지 렌더링 전면 수정

### 프로필 테두리
v17의 실제 원본 디자인을 기준으로 복원했습니다.
원본은 `conic-gradient(별빛 → 심해빛 → transparent → 별빛)` 구조라
좌상단에서 색이 흐려지며 배경이 비치는 부분이 있었습니다.

v22에서는 PNG에서도 유지되도록 이를 SVG 그라데이션 링으로 재현했습니다.
- 사진과 링 사이 여백 없음
- 별빛 / 심해빛 / 투명 페이드
- 바깥 얇은 궤도선 유지
- 최근 버전의 반복적인 색↔색 링 제거

### 이미지 찌그러짐
CSS `object-fit`과 transform 기반 확대를 더 이상 사용하지 않습니다.

이미지의 `naturalWidth / naturalHeight`를 읽은 뒤
프레임 크기에 맞는 cover 크기를 직접 계산해서 실제 px 단위 width/height를 적용합니다.
따라서 원본 가로세로 비율이 수학적으로 고정됩니다.

### 드래그
드래그 시 object-position이 아니라 실제 이미지 left/top 위치를 다시 계산합니다.
- 좌우 이동
- 상하 이동
- 확대 후 이동 범위 증가
- 프레임 밖 이미지는 overflow:hidden으로 잘림

중형 프레임은 1:1, 대형은 가로형을 그대로 유지합니다.
