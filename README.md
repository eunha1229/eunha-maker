# Abyssal Orbit — 메인트 카드 메이커 v20

## v20 수정사항

### 페어 이미지
- v19의 background-image 방식 제거
- 다시 실제 `<img>`를 사용
- `object-fit: cover`로 원본 비율 유지
- 이미지가 프레임 크기에 맞춰 눌리거나 늘어나지 않도록 수정
- 확대는 프레임 안에서 가로/세로를 같은 비율로 함께 확대
- 드래그 위치 조정 유지
- 중형 이미지는 1:1 고정
- 대형은 기존 가로형 프레임 유지
- PNG 저장에서도 동일한 이미지 배치 사용

### 프로필 이미지
- 맨 처음 디자인에 가까운 얇은 이중 원형 테두리로 복원
- 굵은 컬러 링 제거
- 바깥 별빛 링 + 안쪽 심해빛 링
- 사진은 원본 비율 유지 + cover

기존 블록 ON/OFF, 전체폭 중·소형, 빈칸, JSON, Whale PNG 저장 기능은 모두 유지됩니다.
