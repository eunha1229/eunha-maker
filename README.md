# Abyssal Orbit — 메인트 카드 메이커 v19

## v19 핵심 수정

### 페어 이미지 찌그러짐 수정
v18의 `<img> + transform: scale()` 방식 대신,
페어 이미지를 **프레임의 background-image**로 렌더링하도록 변경했습니다.

- 원본 가로세로 비율을 항상 유지
- 기본 상태는 `cover`
- 프레임을 빈틈없이 채우되 이미지 자체는 찌그러뜨리지 않음
- 확대 시에도 원본 비율 유지
- 드래그 위치 조정 유지
- PNG 저장에서도 동일한 배치 유지
- 중형 이미지 프레임은 계속 1:1 고정
- 대형은 기존 가로형 프레임 유지

### 프로필 테두리 재디자인
v18의 두꺼운 컬러 링을 제거하고 원래 분위기에 가깝게 수정했습니다.

- 바깥쪽: 얇은 별빛 원형 링
- 안쪽: 얇은 심해빛 원형 링
- 굵은 형광 띠 없음
- 실제 border 기반이라 PNG 캡처에서도 유지

기존 확대/드래그/위치초기화, JSON 저장, 블록 ON/OFF,
전체폭 페어, 빈칸, Whale PNG 저장 기능은 그대로 유지됩니다.
