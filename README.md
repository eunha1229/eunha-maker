# Abyssal Orbit — 메인트 카드 메이커 v9

## v9 변경사항
- 밝은 테마에서 JOURNAL 영역만 어둡게 남던 문제 수정
- JOURNAL 섹션 전체 배경이 선택한 카드 배경색을 따라가도록 변경
- 헤더형(대) 페어 배경도 카드 배경색 기반으로 자동 조정
- 헤더형 하단 그라데이션에서 검정색 혼합 제거
  - 이제 포인트색(별빛) + 투명도만 사용
- 카드형(중) 배경과 이미지 자리도 배경색/포인트색을 기준으로 자동 조정
- 글자 only(소)도 밝은 테마에서 자연스럽게 보이도록 얇은 adaptive surface 적용
- Abyss 같은 어두운 테마에서는 기존처럼 어둡고, 밝은 프리셋에서는 밝게 유지
- 기존 v8의 메인 글씨색 / 밝은 프리셋 / 별색 / 배경색 / 폰트 / 글자 크기 / PNG / JSON 기능 유지
