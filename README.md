# Abyssal Orbit — 메인트 카드 메이커 v14

## v14 변경사항 — 블록 ON/OFF
편집 패널 맨 위에 **블록 표시** 기능을 추가했습니다.

각 블록을 독립적으로 켜고 끌 수 있습니다.
- 기본 정보
- 태그
- 소개 · 주의사항
- 페어

꺼진 블록은 미리보기에서 완전히 숨겨지고, **PNG 저장에도 포함되지 않습니다.**
따라서 페어나 주의사항이 많아 카드가 길어졌을 때 필요한 부분만 켜서 저장할 수 있습니다.

### 작업 파일 호환성
- v10~v13에서 저장한 기존 JSON 작업 파일도 그대로 불러올 수 있습니다.
- 구버전 JSON에는 블록 표시 설정이 없으므로, 처음 불러오면 네 블록이 모두 ON으로 시작합니다.
- v14에서 저장한 JSON에는 블록 ON/OFF 상태도 함께 저장됩니다.

### 그대로 유지되는 기능
- Whale에서도 동작하도록 수정한 PNG 저장 방식
- GENRE 포함 4종 태그
- 밝은/어두운 테마 및 7종 프리셋
- 폰트/글자 크기
- 헤더형/카드형/글자 only 페어
- 좌측 편집 패널 독립 스크롤
