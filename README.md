# Abyssal Orbit — 메인트 카드 메이커 v6

## v6 변경사항
- 헤더형(대) 페어 디자인 수정
  - 전체에 덮이던 진한 투톤 그라데이션 제거
  - 이미지 자체는 더 깨끗하게 노출
  - 글씨가 위치하는 하단 영역에만 단색 포인트 그라데이션 적용
  - 그라데이션 색은 `별빛` 색상을 사용
- 테마 색상 선택 확장
  - 별빛
  - 심해빛
  - 배경색
  - 별 색상
- 배경색은 카드 전체 기본 배경에 적용
- 별 색상은 작은 점 별과 ✦ / ✧ 장식 별 모두에 적용
- 기존 폰트 / 글자 크기 / 태그 카테고리 / 페어 3종 / 독립 스크롤 / PNG / JSON 기능 유지
