# Abyssal Orbit — 메인트 카드 메이커 v18

## v18 이미지 렌더링 / 조정 개선

### 프로필 이미지
- PNG 저장 시 사라지던 별빛·심해빛 포인트 테두리를 수정했습니다.
- html2canvas가 놓치기 쉬운 conic-gradient 의존 대신 실제 border/DOM 링을 사용합니다.
- 프로필 사진은 항상 원형 프레임에 `cover` 방식으로 채워집니다.

### 페어 이미지
- 대형/중형 이미지가 칸에 맞춰 축소되어 여백이 생기는 현상을 방지했습니다.
- 이미지 프레임은 고정하고 사진은 `object-fit: cover`로 프레임을 꽉 채웁니다.
- 중형(일반/전체폭)의 이미지 영역은 항상 **1:1 정사각형**입니다.
- 대형은 기존 가로형 프레임을 유지합니다.

### 이미지 위치 / 크기 조절
이미지가 있는 대형·중형 페어는:
- 편집창의 `이미지 크기` 슬라이더로 1~3배 확대 가능
- 미리보기 이미지를 직접 드래그해 위치 조정 가능
- `위치 초기화` 버튼 제공
- 위치(X/Y)와 확대 배율은 JSON 작업 파일에 저장

v17 이전 작업 파일도 그대로 열 수 있으며, 기존 페어 이미지는 기본값(중앙/1배)으로 시작합니다.
