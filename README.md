# Abyssal Orbit — 메인트 카드 메이커 v23

## v23 이미지 시스템 재작성

이번 버전은 v22를 덧수정하지 않고, 이미지 문제가 없던 v17을 기준으로 다시 구성했습니다.
이전 실험 버전의 충돌하는 CSS/JS가 전혀 남지 않도록 정리했습니다.

### 프로필 이미지
- v17의 원래 디자인을 기준으로 복원
- `별빛 → 심해빛 → 투명 → 별빛`의 구버전 원형 그라데이션
- 이미지와 컬러 링 사이 여백 없음
- 바깥 얇은 궤도선 유지
- PNG에서 conic-gradient가 사라지는 문제를 막기 위해 컬러 링은 Canvas로 그립니다
- 프로필 사진 자체는 원래 방식인 `object-fit: cover` 사용

### 대형/중형 페어 이미지
CSS 확대/축소를 사용하지 않습니다.
원본의 naturalWidth/naturalHeight와 프레임 크기를 JS가 읽고,
원본 비율을 유지한 cover 크기를 픽셀 단위로 계산합니다.

- 이미지 찌그러짐 방지
- 대형은 가로 프레임
- 중형/중형 전체폭 이미지 프레임은 1:1
- 프레임 밖 이미지는 잘림

### 이미지 조정
- 크기 1~3배
- 미리보기에서 상하좌우 드래그
- 위치 초기화
- zoom/offset은 JSON에 저장
- PNG 직전 이미지 로딩과 위치 계산을 다시 수행

기존 블록 ON/OFF, 빈칸, 전체폭 중·소형, GENRE, Whale PNG 저장 기능은 유지됩니다.
