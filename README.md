# Abyssal Orbit — 메인트 카드 메이커 v5

## v5 변경사항
- ABOUT / NG를 좌우 2열이 아니라 위아래 1열로 변경
- 제목을 `✦ABOUT`, `✦NG`로 변경
- 별 배경을 방식 자체부터 재조정
  - 작은 별 패턴 간격을 약 2배 이상 확대
  - ✦ / ✧ 장식 별은 카드 전체에 몇 개만 남김
- 태그를 3개 카테고리로 분리
  - ✦PLATFORM
  - ✦ACCOUNT
  - ✦DREAM
- 태그 추가 방식은 기존의 `입력 → 추가`를 유지하되 카테고리만 선택
- 결과 카드에서는 박스 없이 카테고리별 한 줄로 출력
- 글자 크기 옵션 재작성
  - 작게 90%
  - 기본 100%
  - 크게 114%
  - 아주 크게 130%
- 기존 CSS의 px 지정에 덮이지 않도록 최종 우선순위 규칙으로 수정
- 손글씨 폰트는 제목/페어명에 별도 가독성 보정
- v3/v4의 좌우 독립 스크롤, 페어 2열, PNG/JSON 기능 유지
