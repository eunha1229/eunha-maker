# Abyssal Orbit — 메인트 카드 메이커 v21

## v21 수정

### 프로필 이미지
- 사용자가 원한 초기 디자인처럼 **심해빛 → 별빛 그라데이션 링**을 복원
- 바깥에는 얇은 별빛 원형 링 유지
- 두꺼운 단색 띠 제거
- 실제 DOM + linear-gradient 구조라 PNG 저장에서도 유지
- 프로필 사진은 원본 비율 유지 + cover

### 페어 이미지
v20에서 사용한 `calc(100% * zoom)` 방식 제거.

새 구조:
- 고정 프레임
- 내부 이미지 캔버스
- 캔버스만 균일한 scale 확대
- 이미지는 항상 width/height 100% + object-fit: cover

결과:
- 원본 비율 유지
- 이미지 찌그러짐 방지
- 프레임 밖 이탈 방지
- 대형은 가로 프레임 유지
- 중형은 1:1 고정
- 드래그 위치 조정 및 크기 조절 유지
- PNG에도 같은 배치 저장

기존 블록 ON/OFF, 전체폭 중·소형, 빈칸, JSON, Whale PNG 저장 기능은 유지됩니다.
